Under the hood

How it works

Content is data

Every monster, quest, item, skill and map is a plain JSON file on disk. The builders write it, the server validates and hot-loads it, and nothing needs a rebuild or a restart.

Server owns the truth

The same simulation code runs on both ends. The client predicts your movement so it feels instant; the server resolves every outcome, so nothing is decided by the browser.

Bring your own assets

Import FBX and GLB models, or drop a file into one folder and refresh — exported objects, meshes and procedural generator modules all register themselves with no catalog to hand-edit.

Where the project stands

Honest status

This is an actively developed solo project. The editors are already capable of authoring rich content, and the multiplayer architecture is server-authoritative from the ground up.

Persistence, a production backend and saved character progression are still in development — accounts created here are the first step toward that. Some assets are visually rough, and skill animations and sound are deliberately parked while the builder systems come first.
