Water

Click-drag to paint water. Shift + drag erases it. Painting automatically carves a basin into the terrain underneath, so the water sits in real ground instead of floating — raising/applying Water Level re-carves that basin deeper too. This is the OLD single-flat-level system — every painted lake shares one height. Use the Lake tool above for lakes at independent elevations with real per-pixel depth.

A lake is a rectangle, optionally with rounded corners (see Edge rounding below) — click "Place Lake" then click the ground to drop one at the size below. Click an existing lake to select it: it gets a yellow outline with four yellow corner handles (drag to resize) and a blue center handle (drag to move). The fields underneath do the same thing numerically and stay in sync with the handles. Doesn't touch the terrain at all, so there's nothing to carve or mismatch — fit it to the ground by eye.

Selected lake

0% = sharp rectangle. 100% rounds by half the short side — a circle when Width and Depth match, an oval/stadium when they don't. Applies to the lake you're placing next as well as the selected one.

Click to add points along the river's path, Enter to finish (rivers are an open path, not a closed shape — no click-to-close). Escape cancels the in-progress draft (or deselects). Each point's height is sampled from the terrain there and automatically clamped so the river can never flow uphill. Click an existing river to select it, then drag its yellow point handles to reshape (height re-samples on drop); Delete removes the selected point.

Shifts the WHOLE selected river up/down by the nudge step, keeping its slope — use this to fit it flush to the ground if it's floating or sunk.

Draw Path

Click to place points. "Finish Path" (or Enter) saves it; "Cancel" (or Escape) discards the draft.

On: each click fixes one point — shown as a dot, with a dashed line to where the next click would land. The solid ribbon is the part that's committed and it does not move again. Double-click (or Enter) finishes the path. Off: click-drag sketches a freehand stroke, for a winding trail.

Locks each new segment's direction to a multiple of the step, measured from the previous point — how you get a road that's exactly straight, or turns at an exact right angle. Hold Shift to force it on while the box is off. Hold Alt to drop a point exactly under the cursor, ignoring both this and path-to-path snapping. Straight segments only.

Recolours the theme's texture. Applies to the draft you're drawing and to every path you draw after it, until you change it back.

While on, a point dropped near an existing path's end (or dragged onto one) jumps exactly onto it, so the two ribbons meet with no seam or gap. Snapping also matches the other path's width, so the join doesn't step. Hold Alt to place a point without snapping. Turn this off if you're drawing alongside an existing road and don't want new points pulled onto it.

Selected Ridge

Nothing selected. Click a drawn mountain ridge.

Width/peak height changes re-raise the terrain when you release the slider. A ridge's drawn shape can't be reshaped after finishing — delete and redraw instead. Deleting a ridge removes its mesh but does NOT flatten the terrain it already raised (use Terrain mode's "Clear All Terrain" for that).

Mountain Ridges (0)

Ground Texture Painting

Click-drag to paint the selected texture onto the ground. Shift + drag erases it. Paths always render above ground textures, regardless of paint order.

Recolours the texture itself, for the whole painted layer. Every ground texture is generated from code rather than loaded from an image, so this is how one texture gives you a dozen shades — a bleached summer meadow, red desert sand, mossy grey cobbles — without a new texture per shade.

Colourfulness runs first, then brightness, then the tint multiplies what's left — so to force a texture to one flat colour, pull Colourfulness to 0 and then pick the tint.

Size/density only take effect once a particle type above is selected (not "None").

Particles render in the live game only — the editor stays a static blockout view, same as it skipping shadows/toon shading.

Selected Light

A hard cutoff, not a suggestion: past this radius the light contributes nothing. That's what keeps a torch inside its own cell instead of glowing through the wall behind it — the shading model has no idea walls exist.

2 is physically correct (bright at the source, dark fast). Drop toward 1 for a flatter fill that keeps a whole room readable corner to corner.

Absolute world height, so a hanging lantern can sit at the ceiling. Placing sets it to the ground you clicked plus 1.5m.

Tilt -90° is straight down (a ceiling spot), 0° is horizontal. The cone is drawn in the 3D view so you can see where it lands.

Only lights within this distance of the camera are lit at all — the pool is small on purpose (8 point + 4 spot at once), and the nearest ones win.

A shadow-casting point light is six full render passes; at most two lights across the whole map get shadows no matter how many you tick. Worth it for the one signature light in a room, never for ambience.

Event Object

Any object can run a scripted command sequence on a trigger — talk/interact, walking into a zone, or a switch turning on. Attach one to an existing NPC, or place a standalone invisible trigger.

Selected Event

Nothing selected. Click a placed event marker, or one in the list below.

Attaching to an NPC replaces its normal dialog with this script entirely. The current target (if any) is outlined in gold in the 3D view — useful when several objects share a name (e.g. two "Treasure Chest" props).

Replaces the Sheets editor below with the full quest form — talking to this NPC will offer/track/turn in a real quest (same engine and same quests.json as Quests mode), with a dialog line per phase. Turns "Start condition" into a fixed Talk trigger.

A quest needs a giver, so this event has to be attached to an NPC first — pick one under "Attached to" above. (Place an NPC in NPCs mode if there isn't one yet.)

Off: a 5m circle around the event, which is all a single NPC or chest needs. On: a box centred on the event, standing on the ground — for a doorway you trigger by walking through, a long market counter, a plate you have to stand on. Shown as a wireframe box in the 3D view.

What the player sees when they're in range. Leave empty for the default ("Press E to talk" / "Press E to interact"). Write the whole line, including "Press E".

Sheets

The FIRST sheet (top to bottom) whose condition passes (or has none) is the one that runs when this object is triggered — put an unconditional fallback sheet LAST. This is how one object's behavior can change over time (e.g. an NPC's line before vs. after you've done something), without nesting branches.
